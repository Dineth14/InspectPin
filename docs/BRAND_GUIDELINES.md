# InspectPin AI brand guidelines

## Brand idea

InspectPin is a precision inspection instrument, not a general-purpose chatbot. The identity combines a restrained technical wordmark, an electric-cyan signal line and a compact `IP` instrument mark. The default presentation is dark, high-contrast and evidence-led.

The source reference named **Internal Arrangement Concept** was not present in the supplied attachment directory. The device illustration in this repository is therefore an explicitly labelled conceptual reconstruction based on the written brief. It must not be presented as a measured enclosure drawing or final industrial design.

## Logo family

| Asset | Use |
|---|---|
| `assets/branding/inspectpin-wordmark-dark.svg` | Primary wordmark on dark surfaces |
| `assets/branding/inspectpin-wordmark-light.svg` | Primary wordmark on light surfaces |
| `assets/branding/inspectpin-compact.svg` | Narrow headers and small lockups |
| `assets/branding/inspectpin-icon.svg` | App icon, favicon and compact navigation |
| `assets/branding/png/` | Raster exports at documented sizes |

Keep clear space equal to the height of the cyan underline on every side. Never stretch, rotate, add a glow, recolour the cyan accent, or place the mark on a visually noisy image. Use the complete wordmark at 120 CSS pixels or wider; below that, use the icon.

Accent cyan is functional: use it for the main action, live signal, focus ring and selected state. It is not a decorative background colour.

## Typography and voice

The interfaces use a system sans-serif stack so the product remains fast and platform-native. Headlines are compact and heavy; supporting text is calm and readable. Uppercase eyebrow labels may be used sparingly with increased tracking.

Product copy is direct and evidence-aware. Say “Analysis has not completed” instead of inventing a result. Say “Simulator” whenever data is simulated. Use “Unavailable” for missing telemetry. Safety and uncertainty statements must remain visible.

## Concept device visual

`inspectpin-device-concept.svg` may be used in onboarding and empty states. Always retain an adjacent **CONCEPT VISUAL** label. Replace it with approved industrial-design artwork only after the physical design is verified.
